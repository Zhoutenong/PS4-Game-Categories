# PS4 游戏分类 App — 产品需求文档 (PRD)

## 1. 背景与目标

将现有 PS4 游戏数据库（`ps4_games.db`）做成一个纯本地的安卓 App，方便用户随时浏览、分类查看、搜索 PS4 游戏。无需网络，无需后端服务。

## 2. 数据说明

数据来源：内置 SQLite 数据库 `ps4_games.db`，只读，随 APK 打包。

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INTEGER | 游戏唯一 ID |
| name | TEXT | 中文名 |
| name_en | TEXT | 英文名 |
| score | INTEGER | 评分（0-100） |
| tags | TEXT | 标签，逗号分隔 |
| primary_category | TEXT | 主分类（如 ACT、RPG） |

## 3. 用户故事

| # | 作为用户，我希望… | 验收标准 |
|---|---|---|
| U1 | 看到所有分类及每类游戏数量 | 首页展示分类列表，显示游戏数 |
| U2 | 点击分类查看该分类下的游戏 | 游戏列表按分类过滤，显示名称、评分 |
| U3 | 搜索游戏（中文名/英文名/标签） | 输入关键词实时返回匹配结果 |
| U4 | 查看游戏详情 | 点击游戏卡片展示全部字段 |
| U5 | 快速了解数据库概况 | 首页显示总游戏数、总分类数 |

## 4. 功能需求

### 4.1 首页（分类列表）
- 顶部显示统计：总游戏数 / 总分类数
- 分类卡片列表，按游戏数量降序排列
- 每张卡片显示：分类名、游戏数量
- 顶部搜索入口（跳转搜索页）

### 4.2 分类游戏列表页
- 标题显示分类名
- 游戏列表：中文名、英文名（副标题）、评分徽章
- 支持按评分排序（默认按 id）
- 点击游戏跳转详情页

### 4.3 搜索页
- 搜索框，输入时实时查询（防抖 300ms）
- 同时匹配 name、name_en、tags
- 结果显示游戏名、分类、评分
- 无结果时显示空状态提示

### 4.4 游戏详情页
- 中文名（大标题）
- 英文名
- 评分（醒目展示）
- 主分类
- 标签（Chip 列表）

## 5. 非功能需求

- **离线**：完全本地运行，不需要网络权限
- **性能**：列表滚动流畅，搜索响应 < 200ms
- **包体**：APK ≤ 15MB（db 约 500KB，可接受）
- **最低 SDK**：Android 8.0（API 26）
- **屏幕**：支持竖屏，适配手机

## 6. 不做的事

- 不做用户账号、收藏、评论
- 不做网络请求、数据更新
- 不做平板/横屏适配（本期）
